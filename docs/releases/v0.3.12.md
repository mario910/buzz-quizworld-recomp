## What's new in v0.3.12

**Build your own round lineup in Question Studio.** This release also improves import and media recovery for older Buzz! games and Knowledge Is Power.

### Custom round plans

- Open **… → Round plans…** to edit the plans for solo, up to four players, and up to eight players independently.
- Add, remove, and reorder rounds. Set the type and question count for each round, including when the same type appears more than once. Leave the count on **Default** to use the usual round settings.
- Studio saves the plans with your project and includes them when you build an `.edat` pack. **Restore defaults** resets the selected player mode.

### Import and media recovery

- Import questions from extracted PS2 discs. Studio preserves questions with distinct source media, can repair missing attachments when you reimport, and recovers usable pictures from partially damaged PS2 picture sheets.
- Improved PS3 imports cover older Quiz TV question files, archives split across multiple regions of an ISO, and European Portuguese. Narration from supported *Brain of…* editions works in preview and pack export.
- Knowledge Is Power narration is matched to the selected question language. The import wizard offers a copyable report with details about skipped entries and media. [Import instructions and tested editions](https://github.com/mario910/buzz-quizworld-recomp/blob/v0.3.12/README.md#import-questions-from-a-game).

### Larger video packs

- Studio streams videos into the pack and no longer applies the shared 256 MiB video budget. The builder reports unsupported media against the affected questions so you can see what was left out. Verified with a pack of 19 videos totaling 278 MiB.

### Updating

Close the game and Studio, then use **Check for updates** in BuzzSetup. Windows and the Linux AppImage can update in place. To update a Linux tarball installation, extract the new package over the existing installation and reopen BuzzSetup.

## What's new in v0.3.11

**Bring your Buzz! and Knowledge Is Power questions into Quiz World with the original categories and media.** This release updates Question Studio on Windows and Linux.

### A guided import

- Choose from the question languages Studio finds in your source. Review the import, recover its media and assign categories without leaving the wizard.
- Keep original categories where available. Knowledge Is Power now uses the game's own translated category names, and a whole source section can be assigned to a category at once.
- Bring supported sorting, linking and ordering rounds into Quiz World as single-choice questions when Studio can derive a correct answer. The import summary reports adapted questions and unsupported answer formats.

### Original sound and video

- Play narration, music and video inside Studio. **Play** can recover just the media for the selected question. **Recover game media** handles the project in bulk.
- Import supported images and music from PS2 and PSP discs, including PSP editions of *Quiz World* and *The Ultimate Music Quiz*. Music clips stay separate from the voice reading the question.
- Studio checks for FFmpeg and can offer installation through a supported package manager.

### Clearer pack builds

- See how many questions are ready before building. If a question has missing media or another issue, Studio shows the reason and can leave it out of the pack.
- We verified a complete Polish *Knowledge Is Power* export of 5,030 narrated questions, including 545 with pictures. We also checked imports from PS2, PSP and PS3 sources. [Tested editions and import instructions](https://github.com/mario910/buzz-quizworld-recomp/blob/v0.3.11/README.md#import-questions-from-a-game).

### Updating

Close the game and Studio, then use **Check for updates** in BuzzSetup. Windows and the Linux AppImage can update in place. For the Linux tarball, extract the new package over the existing installation and reopen BuzzSetup.

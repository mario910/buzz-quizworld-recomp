## What's new in v0.3.10

**Bring more of your original Buzz! questions into Question Studio.** Import
the picture that belongs with a question, or bring over its video clip and
soundtrack for a custom Quiz World pack.

### Question Studio: pictures and clips

- **Import question pictures automatically.** Studio reads stills from the
  PS3 Buzz! SDI sheets and the PS2 Hollywood Quiz RSV sheets, using each
  question's original frame reference.
- **Keep the sound with the video.** Decode supported PS2, PS3 and PSP
  clips to MP4 with their original audio. Use **Decode source media** on one
  question or **Decode all clips** for the whole project.
- **Batch decoding is cancellable.** It decodes shared clips once, leaves
  videos you already attached alone, and lets you undo the new attachments
  together.

Media decoding needs [FFmpeg](https://ffmpeg.org/download.html). Put it on
PATH or select its executable under **Media engine (FFmpeg)** in the build
settings. Text questions still import without it. If an older project
doesn't offer a source clip, reimport from the original disc or pack to pick
up the new references. The Quiz World pack builder accepts clips up to
30 seconds.

### BuzzSetup and Question Studio in 16 languages

Both apps now follow your system language on first launch, falling back to
English, and remember the interface language you choose. Changing the
interface doesn't change the language of your questions or packs.

### More reliable Windows preparation

The Windows build now removes repeated PATH entries before starting the
compiler and ignores certificate overrides that point to missing files.
If Clang still can't be installed, BuzzSetup reports the toolchain problem
directly.

### Updating

On v0.3.9, close the game and Question Studio, then use **Check for updates**
in BuzzSetup. The Windows installation and Linux AppImage can update in
place. For the Linux tarball, extract the new package over the existing
installation and reopen BuzzSetup. Your game saves and settings are kept.

## What's new in v0.3.9

### One click updates BuzzSetup and your game

**Check for updates** in BuzzSetup now handles the whole update for you on
Windows and Linux:

1. BuzzSetup downloads the new release and checks it before using it.
2. It installs the new version and restarts itself.
3. If your game was built by an older release, BuzzSetup rebuilds it right
   away from your prepared disc and firmware. You don't need to choose
   **Update installed game** or prepare the game again.

Your saves, profiles, controls and settings in `dist/runtime/` are kept.

- **Windows:** the ZIP package now updates in place. BuzzSetup closes,
  replaces its files in the `BuzzPrepare` folder and opens again. You no
  longer need to download the ZIP and extract it by hand. If something goes
  wrong, BuzzSetup says why in the activity log when it opens again.
- **Linux:** the AppImage replaces itself and restarts on its own. The tar.gz
  package still has to be extracted over the existing installation; reopen
  BuzzSetup afterwards and it rebuilds the game.

Close the game and Question Studio before you update, so that their files
can be replaced.

### See which versions you have

The top of BuzzSetup now shows the BuzzSetup version and the version of your
installed game, for example `Installed game: v0.3.8`. After the game is
rebuilt, it shows the new version.

### Updating from v0.3.8 or earlier

Older BuzzSetup versions don't have the automatic installer yet, so this one
update works the old way:

- **Windows:** in **Check for updates**, save the ZIP, close BuzzSetup and
  extract the ZIP over your existing `BuzzPrepare` folder. Open BuzzSetup
  again and it rebuilds your game by itself.
- **Linux AppImage:** let BuzzSetup install the update, then open the
  AppImage again. It rebuilds your game by itself.

From v0.3.9 on, later updates are fully automatic.
